## Release blockers

### P0 — Poker Squares is not a playable Poker Squares game

- **Reproduction:** Start Poker Squares, click any empty grid pile, then click the stock. Empty piles do not select a destination; the stock immediately places the card into the first legal `g*` pile.
- **Evidence:** `GameScreen` dispatches the first stock draw, while `poker-squares` exposes one draw move per empty cell. `pileLayout` has no grid layout. `scoreGrid` counts distinct ranks and completed rows only; it does not evaluate poker hands or columns.
- **Impact:** There is no placement decision, the 5×5 grid is not rendered as a grid, and the displayed score is not a poker score.
- **Required fix:** Add a grid-specific board and a two-step draw/place interaction, then implement a tested poker-hand evaluator for all five rows and five columns.

### P0 — Cribbage Squares is not a playable Cribbage Squares game

- **Reproduction:** Start Cribbage Squares and use the stock. The same automatic first-empty-cell behavior occurs.
- **Evidence:** It shares the grid renderer and interaction defect above. Its score is `scoreGrid(...) * 2`, which does not count fifteens, pairs, runs, flushes, or the game’s row/column hands.
- **Impact:** The game has neither the required player choice nor cribbage scoring.
- **Required fix:** Share the grid interaction with Poker Squares, but use an independently tested cribbage scorer and the documented grid dimensions/rules.
